# tlsh_hashes.txt - corpus of known-bad TLSH fuzzy hashes.
#
# Format: <tlsh_hash>,<name>
# Lines starting with # are comments. Blank lines are ignored.
# Same shape as fuzzy_hashes.txt (ssdeep) - see that file's own
# comment and the README's TLSH testing section for the full story on
# why this is a second, separate corpus rather than one shared file:
# a ssdeep hash and a TLSH hash for the same underlying bytes are
# unrelated strings from two different algorithms, matched against by
# two different comparison functions (av_tlsh_diff() here, a distance
# where LOWER is more similar - the opposite of ssdeep's fuzzy_compare()
# similarity score).
